# NestleApp
Maqueta App

## Funcionalidades

### Mi Cuota Disponible
La aplicación muestra la cuota disponible del usuario, incluyendo:
- **Cuota Disponible**: Monto disponible para usar
- **Cuota Total**: Límite total de crédito
- **Cuota Utilizada**: Monto ya utilizado
- **Fecha de Corte**: Próxima fecha de corte
- **Barra de Progreso**: Visualización del porcentaje utilizado

## Uso

Abrir `index.html` en un navegador web para ver la maqueta de la aplicación.
